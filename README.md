# 🌌 PHOENIX

> A modern aesthetic Discord bot built with Python & discord.py.

Phoenix combines moderation, AI interaction, leveling systems, and stylish embeds into one customizable Discord experience.

---

## ✨ Features

╭・🎉 Welcome & Leave System  
╰・Clean animated embed styling

╭・🤖 AI Chatbot  
╰・Powered by Groq API with custom personality

╭・📈 XP & Leveling  
╰・Automatic XP gain, level-ups & rank cards

╭・🛡️ Moderation  
╰・Kick, timeout & utility commands

╭・💎 Aesthetic UI  
╰・Modern embed design inspired by premium Discord bots

---

## ⚙️ Commands

### 🤖 AI
- `!ai <prompt>`

### 🎧 MUSIC
- `!play`
- `!pause`
- `!resume`
- `!skip`
- `!stop`


### 📈 Leveling
- `!rank`

### 🛡️ Moderation
- `!kick`
- `!mute`
